## OCR安装

用户实机日志已确认 `/home/yuting/robot_env/venv` 缺OCR。同学原清单的 `rapidocr-onnxruntime==1.3.24` 要求Python低于3.13，而复制的环境记录是Python3.13.5。现使用同学 `NameOcr` 已提供的 `rapidocr` 导入分支，采用 `rapidocr==2.1.0` 与ONNX Runtime；项目requirements已补齐。

来源：[1.3.24的Python范围](https://pypi.org/project/rapidocr-onnxruntime/1.3.24/)、[2.1.0的Python范围](https://pypi.org/project/rapidocr/2.1.0/)。这不是切换OCR算法或重训模型。

在树莓派执行，两个命令分别复制：

```bash
/home/yuting/robot_env/venv/bin/python -m pip install 'rapidocr==2.1.0' onnxruntime
```

```bash
/home/yuting/robot_env/venv/bin/python -c 'from rapidocr import RapidOCR; RapidOCR(); print("OCR模型加载成功")'
```

仅成功安装不证明OCR已能识别姓名；初始化成功后还需真实立牌测试。初始化可能准备模型，因此在比赛前完成，不在比赛中首次初始化。
