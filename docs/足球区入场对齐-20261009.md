# 足球区入场粗对齐

普通比赛和寻线比赛均在正常action2投放成功后对齐，再调用原足球模块。scan_limit仍跳过足球。不修改配置、标定或原足球模块。

头位沿用sport_head_position（125）。寻找完整双层白框、横向中线及中圈，选择内框；不能只用两条白线。多个不同候选拒绝猜选。先调整长边消失方向，再依据近端内框中心横移，位置容许近端宽度15%的误差。每次动作或完成均需稳定3帧确认。

未找到球场时先右转最多4次，再左转最多8次；次数不是角度。最长60秒、总共最多20次身体动作。已找到后连续3次检测丢失即停止。不盲目前进。

## 预览

```bash
cd /home/yuting/robot_env
PYTHONPATH=app:hardware:lib python3 app/football_align.py
```

只打开头部相机，不连接身体串口，也不发送头部动作。使用原有调头工具先设置合适头位；预览不会自动设置125。绿框应落在足球区内层白线；屏幕显示动作建议，Q退出。确认识别和运动方向后使用原比赛启动命令，两版参数不变。

## 限制与验证

无相机标定，只做粗对齐，不提供厘米或真实角度精度。完整双框和中圈必须可见；球门遮挡远端边框、球遮住中圈、距离过近、反光或歪斜可能导致拒绝识别。对称标记本身无法区分相反的两个球门，目标方向依赖action2在近端这一布局。需用机器人实际画面验证，不能保证现场不误识别。

6项新增测试通过：合成正视/透视图内框检测、干扰矩形拒绝、转向/镜像、横移映射、连续确认与丢失停止、两版调用顺序与失败阻断。普通比赛62项及寻线27项测试通过，修改文件编译检查通过。未在真实机器人上运行，不代表运动方向、平衡或进球验收。
