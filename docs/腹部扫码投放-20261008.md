## 行为

头位127开始找指定颜色物块 → 腹部重新确认、对齐、接近 → HOLD_BOX → 按配置执行RIGHT_HOLDBOX → 腹部解码完整action2 → 每个抱物转向/前进动作后重新观察 → 达到腹部D参考位置和大小，连续确认后DOWN_BOX → 原足球阶段。

实际投放仍比较D位置及宽高；二维码宽高达到参考90%至120%、中心接近且新解码确认后才放下。超过参考120%停止。腹部D是图像参考，不是厘米测距。

## 先抱物，再标定腹部D

标定入口保持无身体动作，不会自动站立、抱取或放下。先将物块放到正确抱取位置，扶稳机器人并留出站立和抱物空间。以下准备指令自动站立一次、等2秒，再抱起一次，关闭串口时不发送放下指令：

```bash
cd /home/yuting/robot_env
venv/bin/python - <<'PY'
import sys
import time
sys.path.insert(0, "app")
import robot_config
from robotmove import RobotMove
from competition_main import BODY_PORT
robot = RobotMove(None, port=BODY_PORT)
try:
    time.sleep(2)
    robot.robotMove("HOLD_BOX")
finally:
    robot.close()
PY
```

保持实际抱物姿态，将机器人放到action2附近适合执行放下动作的位置。先备份现场参考，再进入标定：

```bash
cp -n config/carry_dual_reference.json config/carry_dual_reference.before-belly-drop.json
bash setup_head_pwm.sh start
ROBOT_HEAD_PWM_BACKEND=pigpio \
venv/bin/python competition.py --run --calibrate-carry --color blue
```

以上沿用现场相机配置。若USB路径仍错误，先枚举 `/dev/v4l/by-id/`，使用真实存在的头部设备路径设置ROBOT_KICK_HEAD_DEVICE；不要照抄错误的video-index，也不要猜编号。

确认 **carry belly** 窗口完整、稳定解码到唯一action2，按D保存，Q退出。D需5次稳定结果，最终放下需3次确认。无需按H；D保存保留原H，但写入新目的地和腹部D。新D记录 `drop_camera: "belly"`，去掉旧drop_head_position。旧头部D（包括127头位D）一律不用于腹部投放。仅退出而不按D不会更改现场参考。

```bash
venv/bin/python competition.py --check
ROBOT_HEAD_PWM_BACKEND=pigpio \
venv/bin/python competition.py --run --actions --color blue
```

预检要求有效腹部D；--use-original-drop不绕过这一要求。若预检报告相机配置/尺寸不匹配，先恢复现场已确认的配置，不覆盖H或取消检查。
