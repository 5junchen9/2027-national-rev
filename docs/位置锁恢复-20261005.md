# 位置锁恢复

## 本次改动

保留旧球检测与多轮头部搜索，只修改位置锁恢复，不增加圆弧筛选。

正常情况下仍优先跟踪旧位置附近的球。只有旧位置没有合格候选、画面其他位置存在通过颜色、形状和原尺寸条件的候选时，才累计位置拒绝次数。

连续3帧位置拒绝后，开始确认新的候选位置。新候选连续3帧位置、尺寸基本一致后重新锁定（第3次拒绝也算第1帧确认，因此最快第5帧重新锁定）。若新候选在不同位置跳动，确认重新计数；没有候选或旧位置重新出现球时，取消此次恢复。

恢复后连续识别和位置稳定计数从1开始，身体仍需等待原有稳定确认。自动视觉重找保留正在确认的新位置，手动R仍完全重置位置。原颜色学习和大小筛选条件保留。

画面提示 `outside target lock: retry=.../3 confirm=.../3` 表示正在处理位置锁拒绝。若提示 `no ball shape/color`，应检查颜色、形状或尺寸条件，本次改动并不能解决所有漏检。连续出现的同色同形其他物体仍可能被重新选中，确认次数不是真实身份认证。
