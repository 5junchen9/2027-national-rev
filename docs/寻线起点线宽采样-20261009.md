# 行走过程中线宽采样与候选筛选（2026-10-09）

针对远处二维码白边被当成路线，新增线宽参考。不改现有全画面检测、底部25%纠偏取样、平移优先和右弯动作规则。

## 工作方式

- 每次进入实走寻线重新采样，参考只存在内存中，不写配置。纯预览不执行前进，因此不建立线宽参考。
- 起步照常使用原寻线规则。前一次UP_LITTLE调用正常返回后，下一幅新图仍有近线且决策仍为UP_LITTLE，才采样。采样要求方向接近竖直（±10度），不具备判断路线身份的能力。动作返回及图像稳定不等于已用传感器确认物理位移。
- 随行走积累10幅有效图，不要求连续。转向、WAIT、物块确认、无近线、无法量到宽度以及位置/角度跳变的帧不采；保留已经积累的有效样本。位置跳变标准为画宽6%，角度为10度。
- 按画面高度每隔24像素取样，只记录与所选近线延长方向相近、实际有线段覆盖的位置。每个高度至少7帧有宽度记录，取中位数作为参考。
- 沿线段的垂直方向量白带宽度。采样完成后固定参考，不在线更新。
- 后续竖直段和右弯斜段都接受筛选：同高度宽度必须在参考的70%至130%之间，超过半数测量位置合格才保留。没有参考覆盖的线段暂时放行。
- 采样未完成时使用原寻线决策，不为采样额外WAIT、等待相机或增加动作间隔。每个循环最多测量当前一幅图，不增加线程。采满后从下一循环启用宽度筛选。头部物块确认和退出机制继续保留。

## 现场使用

先把真实直线放在腹部视野中央，尽量让直线同时覆盖近处和上方区域。实走显示 `width sampling n/10`，期间正常行走；完成后显示 `width locked +/-30%`。一直未完成时仍按原规则寻线。纯预览显示 `width inactive (preview)`，只观察原始寻线决策。

只预览（在现场环境变量已准备好的终端）：

```bash
cd /home/yuting/robot_env
venv/bin/python competition_line.py --run --preview --line-color white
```

只测试寻线并执行身体动作（站立行走时做好防倒保护）：

```bash
venv/bin/python competition_line.py --run --actions --line-only --color red --line-color white
```

每次实走重新采样；退出进程即清除参考。`line mask`窗口仍显示二维码排除后的白色掩膜；`line search`窗口的绿/橙线才是经过宽度筛选后的候选。
