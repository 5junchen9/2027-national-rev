## 使用步骤

以下命令在树莓派执行。本机已做检查和无硬件模拟，没有发送真实动作。

```bash
cd /home/yuting/robot_env
./venv/bin/python competition.py --check
./venv/bin/python competition.py --simulate --color blue
```

若二维码依赖缺少，项目原 `setup.sh`、`requirements.txt` 已列出依赖；只补缺少的部分：

```bash
sudo apt install libzbar0
./venv/bin/python -m pip install pyzbar
```

先启动现有头部PWM服务，并在同一个终端设置已使用过的相机参数。保持这些参数一致进行预览、标定和比赛。**下面双摄预览仅在枚举结果重新出现真实腹部CSI相机后运行**；当前只有USB时不要猜腹部编号，也不要把0直接改成1。示例编号0来自此前双摄枚举，使用前必须重新确认：

```bash
bash setup_head_pwm.sh start
export ROBOT_HEAD_PWM_BACKEND=pigpio
export ROBOT_CAMERA_FOURCC=MJPG
export ROBOT_KICK_HEAD_DEVICE=/dev/v4l/by-id/usb-lihappe8_Corp._USB_2.0_Camera-video-index0
export ROBOT_KICK_BELLY_DEVICE=0
./venv/bin/python competition.py --run --preview --color blue
```

预览打开双摄并把头定位到120；不打开身体串口。查看二维码完整文本、腹部蓝地近远比例和指定色方块，按Q退出。

可先单独验证姓名/性别和播报，不依赖搬运/足球标定。以下命令会打开头部USB、把头舵机定位到120并播放声音，不打开身体串口：

```bash
ROBOT_CAMERA_DEVICE="$ROBOT_KICK_HEAD_DEVICE" ./venv/bin/python app/competition_identity.py \
  --legacy-root /home/yuting/Desktop/robot_legacy --head-position 120 --timeout 60
```

2026-10-06 预览提速：`app/competition_identity.py` 将人脸检测、FairFace和OCR放到一个后台线程，主线程持续显示最新画面。只允许一个识别任务在执行，完成后才提交最新帧，不积压旧图。连续确认仍要求三次实际识别一致；没有人脸或姓名时清零。模型、裁剪和OCR整帧回退保持原样。

画面上的 `Preview ... FPS` 是实际预览刷新率，不是识别次数；`D / G / OCR` 分别是最近一次检测、性别和姓名识别的秒数，终端也输出中文耗时。按Q或Esc退出，资源释放会等待当前一次推理完成。识别期限从模型加载和相机准备完成后计算。本机26项比赛测试通过，其中包括慢推理期间预览继续刷新、不积压任务与不重复确认；树莓派实际帧率和识别准确率仍需现场验证。本次只修改比赛适配入口，没有修改同学原版 `Desktop/robot_legacy/app/face_main.py` 或旧五人识别入口。

搬运H/D标定使用新入口，确保公众号码由同一解码器读取：

```bash

```

此模式头位129，不打开身体串口。机器人保持已经实测的标准站姿：把指定色物块放在能稳定抱起的位置，腹部唯一稳定框出现后按H；把公众号码放在能投放的位置，头部唯一稳定框出现后按D；Q退出。更新 `carry_dual_reference.json`。目的地二维码变化必须重新D标定，颜色变化需核对物块大小与抱取位置。

足球继续沿用原 `head_calibration.json` 和 `right_foot_reference.json`，没有新建虚假的标定。必须确认双摄配置、尺寸、初始头位129与现有标定一致。

通过检查并逐段实测后，整场启动：

```bash
./venv/bin/python competition.py --check
./venv/bin/python competition.py --run --actions --color blue
```

临场颜色用 `red`、`blue` 或 `yellow`。不指定 `--color` 时启动询问颜色。

## 现场需要改的配置

配置文件为 `config/competition.json`。次数均为已有完整动作的重复次数，不是角度值：

- `after_sber_steps`：读到sber后额外前进，初值1。
- `sber_right_actions`、`action1_right_actions`：两处45度转向，初值各4，需实测。
- `delivery_search_right_actions`：抱物寻找目的地的最多右转次数，初值5。
- `return_right_actions`：红/蓝/黄投放后的回程方向分别标定，初值均4。
- `after_return_steps`：回程后额外前进，初值1；`after_sport_right_actions`：足球后90度转向，初值7。
- `face_head_position`、`dance_head_position`：初值120，按实物画面调整。
- `blue_roi_near`、`blue_roi_far`、`blue_min_ratio`、`blue_extra_steps`：舞区画面范围、蓝色比例和确认后的补偿步数。

这版未实现地面线循迹或全场定位；只靠固定右转次数不能保证搬运后回到赛道。四次与七次右转、三种颜色的回程和蓝地判据必须现场校准。实机记录按大纲的验收顺序进行，最后再验证整轮8分钟。
