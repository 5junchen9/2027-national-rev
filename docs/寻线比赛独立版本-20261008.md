# 寻线比赛独立版本

原版已保存在Git提交 `e5e6757`，原入口 `competition.py` 和其路线不改。新入口 `competition_line.py` 复用现有摄像头、身体动作、搬运、足球及舞蹈模块。

流程：腹部face → 后退一步 → 右转一次 → 单帧下蹲 → 头位131识别并播报 → 站起 → 左转一次 → 沿线前进及右弯搜索 → 指定颜色物块确认 → 搬运到action2 → 足球 → dance及蓝地 → 舞蹈。

新版不识别left/action1作为路线节点，不执行对应的各3次右转。头位127观察物块，同一指定颜色物块连续3帧且相邻框IoU大于0.3才进入搬运；首次出现候选即暂停移动确认，消失则恢复寻线。

参考 `../Desktop/robot_legacy/app/line_follow.py` 的底部20%区域、质心偏差和分级控制。为蓝地浅色线增加白线检测（默认），可用 `--line-color black` 选择同学原有灰度100黑线检测。按连通区域选择接近上一次线位置的候选，而不是混合所有暗色像素。

近段看底部80%-100%，远段看55%-75%。近段线居中时，远段线向机器人右方偏移超过640宽下60像素则提前右转；水平翻转画面会换算为机器人方向。正常偏差中等平移，较大转向。

地图两处弯道均为右弯：连续两幅新图没有近段线，原地向右搜索，每次动作后重读相机，最多4次，找回线即恢复跟随。仍无线路且未确认物块则停止，不把丢线当作搬运入口。30轮或90秒上限仍保留；候选物块的确认也占循环轮数。

4次右搜索是动作次数，不等于45度。两处右弯仅作为搜索方向先验，没有按转向动作次数推断已完成两个弯道。物块可能在远处提前可见，此时会交给已有搬运模块继续找物和接近；颜色/外形误检仍需实测。白线检测可能识别地板文字/横线，黑线检测可能识别深色图案；先用预览验证近段红点、远段紫点是否跟随同一条目标线。

部署只新增：

不用覆盖原流程，不用改现场配置/标定；依赖上一轮已经同步的原版模块和下蹲动作。
