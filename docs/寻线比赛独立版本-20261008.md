# 寻线比赛独立版本

原版已保存在Git提交 `e5e6757`，原入口 `competition.py` 和其路线不改。新入口 `competition_line.py` 复用现有摄像头、身体动作、搬运、足球及舞蹈模块。

流程：腹部face → 后退一步 → 右转一次 → 单帧下蹲 → 头位131识别并播报 → 站起 → 左转一次 → 沿线前进 → 出线后局部搜索 → 搬运到action2 → 足球 → dance及蓝地 → 舞蹈。

新版不识别left/action1作为路线节点，不执行对应的各3次右转；物块出现也不是寻线终止条件。

参考 `../Desktop/robot_legacy/app/line_follow.py` 的底部20%区域、质心偏差和分级控制。为蓝地浅色线增加白线检测（默认），可用 `--line-color black` 选择同学原有灰度100黑线检测。按连通区域选择接近上一次线位置的候选，而不是混合所有暗色像素。

线居中前进一小步；偏差中等平移，较大则转向。连续两幅图没有线，依次右转、左转回中、左转、右转回中，观察后仍没线且已经沿线前进至少一步，视作出线并进入搬运。最初没线则有限搜索后停止；超过原配置的30次动作或90秒则停止，不作为到达终点。

上述左右搜索次数是动作次数，不是已标定的相等角度，实际可能不能精确回中。短暂遮挡、漏检或弯道也可能被判成出线；此版本不能证明已经到搬运区域，需现场验证。白线检测可能识别地板文字/横线，黑线检测可能识别深色图案；先用预览验证底部黄线下方红点是否跟随目标线。
