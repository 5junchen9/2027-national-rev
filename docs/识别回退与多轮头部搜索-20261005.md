## 部署

将以下三个文件一起拖入树莓派 `/home/yuting/robot_env/app/`，覆盖同名文件：

- `ball_debug.py`
- `handover_debug.py`
- `walk_kick.py`

不要覆盖现场 `config/`。启动命令不变：

```bash
cd /home/yuting/robot_env

```
