# 原功能与新入口

| 功能 | 新入口 | 保留内容 |
|---|---|---|
| USB-TTL语音总控 | main.py voice --run | 1–9、12–15、0及原中文方向口令，断线重连 |
| 人脸姓名识别 | main.py face --run | 五个人名、EIM/Haar模型、原姓名录音、连续确认及超时 |
| 二维码文字/图片路线 | main.py qr | F/L90/R90、URL与图片、路线预览、转弯标定 |
| 固定搬运 | main.py carry --run | 抱起→前进3次→放下、低头及平视恢复 |
| 双摄反馈踢球 | main.py kick --mode dual --preview/--run | 头USB看门和球，腹CSI接管近处球；实测标定后右脚只踢一次，未标定拒绝运行 |
| 原固定踢球 | main.py kick --mode fixed --run | 旧固定左脚动作保留 |
| 舞蹈 | main.py dance --run | 第1/3/4/5段，背景音乐随动作结束停止；第2段文件保留 |
| 方向移动 | 语音6–9或main.py action --run | 左右大转弯7次、前后行走及原速度倍率 |
| 情绪交互 | main.py emotion --run | 开心、伤心、最多重试一次，伤心触发舞蹈 |
| 唱歌、讲笑话 | main.py song/joke --run | 原音频，不单独初始化机器人串口 |
| 中文动态女声 | main.py speech | 离线Matcha Baker、录音优先、语速、峰值控制 |
| 麦克风语音口令 | main.py mic --run | 原Vosk口令，补齐中文模型，支持ASR词间空格 |
| 五项顺序流程 | main.py all --run | 调用当前任务插件，机器人连接复用一次 |
| 颜色标定 | main.py calibrate --run | 原鼠标采样、多颜色阈值及全部HSV数据 |
| 摄像头、圆形预览 | main.py camera/round --run | 原USB默认；15fps/预热/重开与圆形识别；CSI仅在新版双摄踢球独立接入 |
| 无动作模型诊断 | main.py vision --model face或emotion | 元信息、已裁剪图片完整分数、测试集混淆统计，不打开硬件 |
| 串口工具、协议检查 | main.py serial / main.py protocol check | 参数/文本/HEX工具，DreamMaker帧检查 |
| 厂商历史程序、旧视觉寻物 | legacy目录 | 原文件保留供对照，当前固定搬运/踢球行为不被旧代码覆盖 |
| 开机启动 | 不包含 | 按用户要求不创建/启用任何开机启动项 |

源文件与迁移去向详见source_manifest.json。缓存、旧安装压缩包及自启安装脚本未放入新环境，
这些文件仍保留在原现场。旧b3、robot中的重复代码和资源仅作为历史参考，不参与新版导入。
