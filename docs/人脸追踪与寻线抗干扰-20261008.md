# 人脸追踪与寻线抗干扰

人脸改进同时作用于原比赛和独立寻线版：
- 保留实测131初始头位；检测到人脸偏高/偏低时每次微调1个命令单位，范围125至137，动作间隔至少0.8秒。只调整上下头位，不移动身体，不将没有脸时的盲扫混入识别。
- 使用非阻塞头部调整，稳定后再提交新推理；调整后重新计姓名确认次数。
- 姓名只裁人脸下方局部并三倍插值放大，不再回退整图OCR。只接受2至4个汉字、置信度至少80%的候选。
- 同一姓名和性别在三次独立OCR更新中确认才播报；隔帧缓存不重复计数。插值不能恢复原图没有的笔画，也不能保证高置信度候选必然正确；有名单时可另做候选约束，本版没有虚构姓名名单。
- 原60秒上限内未完成则跳过播报，恢复路线后正常站起、左转继续。Q/Ctrl+C仍停止比赛，摄像头故障和比赛总时限仍停止，不会作为姓名缺失跳过。

寻线改进只作用于独立寻线版：
- 用OpenCV定位二维码，遮挡其区域和外扩边缘；不解码left/action1，不用二维码触发路线。
- 检测细长且覆盖当前近/远区域至少55%高度的候选，限制横向宽度、拒绝短亮斑和大块白纸。
- 有上一线位置时，候选横向跳变不能超过画面宽度18%。近远段共用一次二维码遮挡掩膜。
- 依然保留右弯提前观察、有限向右搜索及物块三次确认；无法确定线路时停止。

反光如果与真实路线同样细长、连续，单帧颜色/形状不能保证区分。先预览验证；必要时改善漫射照明、胶带表面或机位。截图中的树莓派还出现了低电压提示，供电状态需现场检查。

部署更新app中的competition_main.py、competition_identity.py、competition_line_main.py、line_search_route.py，新增identity_tools.py。不用修改competition.json或搬运标定，也不修改同学robot_legacy目录。

验证：71项本地测试通过；包括姓名局部三倍放大、低置信度拒绝、独立OCR确认、头部范围、识别未完成继续路线、Q停止、二维码遮挡、短亮斑排除和线位置跳变限制。实机OCR准确率、反光抑制和帧率仍须确认。
