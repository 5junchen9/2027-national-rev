# 指定人脸训练数据

现有 Haar 分类器只负责从摄像头画面中裁出人脸；后续模型负责判断“这是谁”。

## 目录结构

在本目录中，为每位需要播报姓名的人建立一个英文或拼音目录名：

```text
data/faces/
├─ zhangsan/
│  ├─ 001.jpg
│  ├─ 002.jpg
│  └─ ...
├─ lisi/
│  ├─ 001.jpg
│  └─ ...
└─ unknown/
   ├─ 001.jpg
   └─ ...
```

- 目录名是程序内部标签，例如 `zhangsan`；播报的中文姓名在后续配置中单独对应。
- `unknown/` 放非目标人员的人脸，用来验证系统会拒绝陌生人；不要将其误播报为目标姓名。

## 每位人员应提供什么数据

每位目标人员建议先提供 **80 到 150 张** 清晰照片；先小规模验证，再按误识别情况补充。每张照片只保留一张脸。

照片应覆盖：

1. 正脸、左右轻微转头、轻微抬头或低头。
2. 近、中、远三种距离，尤其是模拟场地中摄像头实际识别距离。
3. 明亮、偏暗、侧光等现场常见光照。
4. 不同表情、是否佩戴眼镜，以及常用发型或帽子状态。
5. 不同拍摄时段和背景，避免所有照片来自同一段连续视频。

不要投入：

- 模糊、严重遮挡、逆光到看不清五官的照片；
- 多人合照；
- 从同一视频连续截取的大量几乎相同画面。

## 数据划分

每位人员按拍摄时段分为：

- 训练集：约 70%。
- 验证集：约 15%。
- 测试集：约 15%。

测试集必须来自不同拍摄时段，不能与训练集是相邻视频帧。训练完成前不要把照片移动到模型目录。

## 数据安全

仅收集已获得本人同意的照片。照片仅用于本机器人离线测试，不上传公开平台；测试结束后按项目要求删除或归档原始人脸数据。

## 下一步

数据到位后，先在电脑上确认 Haar 能稳定裁出人脸，再训练轻量级身份识别模型。导出的模型和标签表将放入 `b3/2/models/face/`，随后才修改 `day3new.py`：只有识别结果为目标姓名且置信度达标时，才播放对应姓名音频并进入下一任务。
